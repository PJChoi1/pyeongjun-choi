# Pyeongjun Choi — Personal Homepage

Academic homepage for **Pyeongjun Choi** (Ph.D. Student, DGIST / ICNL).

Built with the [HTML5 UP Dopetrope](https://html5up.net/dopetrope) template (same family as [ICNL](https://icnl.korea.ac.kr/)).

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```
